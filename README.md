# 🎬 Buscador de Películas

Aplicación web interactiva que permite buscar información de películas en tiempo real consumiendo la API pública de **OMDb**, desarrollada con HTML, CSS (Bootstrap 5) y JavaScript moderno.

## 🚀 Características

- 🔍 **Búsqueda interactiva:** Permite buscar películas por su título.
- ⚡ **Fetch API:** Consultas asíncronas a una API externa sin recargar la página.
- 🎨 **Diseño Responsive:** Interfaz adaptable en modo oscuro utilizando Bootstrap 5.
- ⚠️ **Manejo de errores:** Notificaciones dinámicas para búsquedas sin resultados o fallos de red.

## 🛠️ Tecnologías utilizadas

- **HTML5** (Estructura semántica)
- **CSS3 / Bootstrap 5.3** (Estilos y layout)
- **JavaScript (ES6+)** (Consumo de API con `fetch()` y manipulación del DOM)
- **OMDb API** (Servicio web de películas)
